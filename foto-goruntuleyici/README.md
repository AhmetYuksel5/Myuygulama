# Fotoğraf Görüntüleyici (Windows)

JPG ve PNG açan, tek dosyalık basit bir görüntüleyici.

## Kurulum

1. GitHub Releases'ten `FotoGoruntuleyici.exe` dosyasını indir (`foto-v…` etiketli sürümler).
2. Kalıcı bir klasöre koy, örneğin `C:\Uygulamalar\`. Varsayılan uygulama kaydı
   exe'nin durduğu yeri gösteriyor; İndirilenler'de bırakıp sonra silersen kayıt boşa düşer.
3. Çalıştır. İmzasız olduğu için Windows "bilgisayarınız korundu" diyebilir:
   **Ek bilgi → Yine de çalıştır**.
4. İlk açılışta "varsayılan yapılsın mı?" sorusuna Evet de. Ayarlar açılınca
   .jpg, .jpeg ve .png için Fotoğraf Görüntüleyici'yi seç. Windows bu son
   tıklamayı uygulamaların kendisinin yapmasına izin vermiyor.

## Kullanım

| Ne | Nasıl |
|---|---|
| Yakınlaştır / uzaklaştır | Ctrl + tekerlek (imlecin olduğu yere) |
| Sonraki / önceki fotoğraf | Tekerleği sağa / sola yatır, farenin yan tuşları, ← → |
| Kaydır | Sol tuşla sürükle |
| Pencereye sığdır | Çift tıkla ya da Ctrl+0 |
| Gerçek boyut | Ctrl+1 |
| Dosya aç | Ctrl+O, sürükle bırak ya da boş pencerede çift tık |
| Tam ekran | F11 (Esc çıkar) |
| Varsayılan uygulama yap | Sağ tık menüsü |

## Kendin derlemek istersen

`derle.bat` dosyasına çift tıkla. Windows'ta hazır gelen derleyiciyi kullanıyor,
ek bir şey kurman gerekmiyor.
